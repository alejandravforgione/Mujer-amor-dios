# Mujer, Amor y Dios — Plataforma Web

Repositorio del proyecto web para el proyecto audiovisual y podcast **Mujer, Amor y Dios**.

## 🛠️ Tecnologías utilizadas
* **Frontend:** React + TypeScript
* **Estilos:** Tailwind CSS
* **Build Tool:** Vite

## 📋 Descripción del proyecto
Plataforma web diseñada para gestionar invitaciones, presencia digital e identidad del proyecto.

## 🚀 Cómo ejecutar localmente
1. Clonar el repositorio
2. Instalar dependencias: `npm install`
3. Iniciar entorno de desarrollo: `npm run dev`
